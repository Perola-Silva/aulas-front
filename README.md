# Estudos em Front-end (HTML e CSS)

Este repositório reúne exercícios e exemplos desenvolvidos durante os estudos de **HTML5** e **CSS3**, abordando desde a estrutura básica de páginas web até conceitos modernos de layout responsivo, Flexbox e Grid Layout.

Os arquivos foram criados com o objetivo de praticar os principais fundamentos do desenvolvimento front-end, seguindo uma evolução gradual dos conteúdos.

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute qualquer arquivo `.html` em um navegador de sua preferência.

Também é possível utilizar extensões como **Live Server** no Visual Studio Code para facilitar o desenvolvimento.

## Objetivo

Este repositório tem como finalidade registrar a evolução dos estudos em desenvolvimento Front-end utilizando HTML5 e CSS3, reunindo exemplos práticos, exercícios e páginas desenvolvidas durante o aprendizado.

Os arquivos estão organizados por assunto, permitindo consultar facilmente os conteúdos estudados e acompanhar a evolução no desenvolvimento de interfaces web.
