O poder das variáveis

As variáveis, ou Custom Properties tornam o código CSS mais fácil de manter e organizar, principalmente quando se precisa mudar aspectos visuais de acordo com alguma preferência ou interação do usuário (exemplo:mudança de paleta de cores do site).

Exemplo: Se quissermos mudar a cor do link abaixo e do título, bastas alterar apenas a variável que define a cor destes elementos
