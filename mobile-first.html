Media Queries - Mobile First

Conceito

Media Queries são regras especiais em que criamos alterações na página de acordo com determinadas condições (exemplo: tamanho da tela).

Essas alteraçoes ocorrem coma a configuração de breakpoints.

As midia queries são aplicadas de acordo com a estrategia usada para desing responssivo, podendo ser:

  • Mobile First:Do pequeno para o grande
  • Desktop First:Do grande para o pequeno
